# Desain-HCI-UX---SantapOnline-
Santap Online adalah aplikasi pemesanan makanan berbasis web yang dikembangkan menggunakan HTML, CSS, dan JavaScript. Aplikasi ini menyediakan fitur pencarian menu, keranjang belanja, perhitungan biaya, formulir pengiriman, serta simulasi pembayaran dan pelacakan pesanan dengan desain responsif dan antarmuka yang mudah digunakan.
